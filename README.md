# Super Pong

Neon two-player games for one phone, held sideways. The first game is **Super Pong**.

**Play:** https://edwardrowe.github.io/super-pong/

Each player swipes up and down on their half of the screen. On a computer, use W/S and ↑/↓.
For full screen on a phone, use your browser's *Add to Home Screen*.

## Develop

```bash
npm install
npm run dev      # http://localhost:5173 (also on your local network)
npm test
npm run build
```

Every push to `main` is tested, built and deployed to GitHub Pages.
